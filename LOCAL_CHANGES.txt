GlassBoard 本地修改版：分组拖动排序 + 去除大面板底部署名 + 去掉 Dock 悬停浮窗

使用：按住上方自建分组左右拖动。目标分组左半边表示插入其前方，右半边表示插入其后方；蓝色边线指示插入位置。
松开后自动保存，取消拖动不改变顺序。Ctrl+Z 撤销、Ctrl+Y 重做（焦点不在文本输入框时）。
“全部”和“未分组”固定在前两位。拖入应用仍然用于归类，分组排序不修改应用归属。

代码基于原包 v0.2.0（上游说明基于 v0.9.23）。保留原许可证、作者支持页和第三方素材。
本地变更：

   - src/DockInteractions.cs 在共用的悬停层创建函数里调用 ToolTipService.SetIsEnabled(element,false)，所有 Dock 元素（应用图标、分组、对话框卡片、固定按钮、边缘感应区、运行指示点等）生效；
   - src/GlassBoard.cs（原设置 0 ms 初始延迟 / 10 秒显示时长的位置）改为 ToolTipService.SetIsEnabled(b,false)。
   提示字符串本身保留（ShowLabels 改名、AddSystemButton 命名仍会读取它），只是永不显示浮窗；悬停放大/上抬动画与提示浮窗互不影响，仍可在“设置 → UI 动效”里单独开关。
   注意：Dock 顶部拖动条的 ToolTip（“拖动 Dock；在设置中可锁定位置”）按本次范围要求未改动。

3. 空闲开销调优（本轮新增，源码 src\IdleState.cs）：
   - 新增 src\IdleState.cs：包装 GetLastInputInfo，500 ms 缓存一次，供各处判断“用户是否真的在操作”；阈值 IDLE_AFTER=20 秒、复查 REIDLE_AFTER=5 秒。

10. Dock 点击与任务栏一致：记住真实前台窗口（2026-10-30）
- 症状：Dock 图标点击永远只是“激活/前置”，从不会最小化；主面板图标却正常。
- 根因：Dock 窗口构造为 ShowActivated=false，且 Hook 对 WM_MOUSEACTIVATE(0x21) 返回 MA_NOACTIVATE(3)，点击时 Windows 把前台窗口清空，GetForegroundWindow() 返回 0；“目标是否已在最前”恒为假，Toggle 只能走激活分支。主面板因为会自己抢前台，才拿到前台提示。
- 修复：RunningWindows 增加 remembered 前台缓存。RememberForeground() 忽略前台为 0、本进程窗口与 Shell 界面（Shell_TrayWnd/Shell_SecondaryTrayWnd/Progman/WorkerW/Windows.UI.Core.CoreWindow/MultitaskingViewFrame/ForegroundStaging/空类名）；EffectiveForeground() 在真实前台无效时回退缓存。Toggle/ToggleWindow/ForegroundMatch/CaptureForegroundHint 全部改用 EffectiveForeground()。回退链本身要求缓存窗口仍然 IsWindow 有效。
- Dock 点击在指针按下时记录 pointerHint：DockInteractions.StartPointerItem → LaunchDock(entry, pointerHint) → RunningWindows.ToggleDock(entry, hint) → Toggle(entry, hint)，与主面板 BoardWindow.foregroundHint 语义一致。
- Controller 新增 300ms 的 foregroundTimer 轮询（原来只有开启自动隐藏时 autoTimer 才跑）；ReleaseHotkey 时停止。
- 新增诊断 trace：WINDOW decide handle/hint/fg/fgpid/fgtitle/front/iconic，配合 WINDOW pick 可一眼看出前台判定为何失败。
- 实测（真实屏幕点击，DPI 感知）：前台为 douyin 时点 Dock 抖音图标 → hint=67306 fg=67306 front=True iconic=False → WINDOW minimize handle=67306，第一次点击就最小化；点已最小化的 DeepSeek Harness 图标 → front=False iconic=True → 恢复并置前。
- 事故与修复：一次合成点击被判定为拖拽，revision 1154 把抖音从第 4 位挪到第 7 位；已按 layout.json.previous(revision 1153) 的顺序写回并重启（启动后 SAVE revision 1155）。合成点击在 hover 动画期间不可靠，后续不要用连续合成点击验收 Dock。
