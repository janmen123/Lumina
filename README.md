# Lumina v0.2.0

本包撤回 v0.9.24，恢复 v0.9.23 基础，取消系统玻璃美化。

## 使用

先从系统托盘完全退出正在运行的 Lumina，再把本包解压到新文件夹，运行 Start.cmd 或 Lumina.exe。不要只用 EXE 覆盖旧目录。无需删除配置文件，已有布局、分组、Dock、组件和便签继续沿用。

如果之前加载的系统玻璃效果还残留，退出旧版后稍等约 15 秒；仍残留时注销 Windows 后重新登录。回退包不再加载该模块，也不会强制重启 Explorer。

## 本次修正

- 修正点击原生托盘后，再点小球又自动进入托盘并收起的循环。再次点击小球默认正常展开控制中心；只有明确点击托盘入口才发起托盘操作。
- 托盘调用独立于控制中心操作状态，放入单独辅助进程并设置约 3 秒超时。旧请求的迟到结果不会覆盖刚重新打开的面板。
- 修正立即收起与未结束的淡出动画之间的状态冲突。
- 首次运行本修订时默认关闭展开/收起、翻页、缩放悬停和弹簧过渡，保留即时高亮与点击反馈；样式选项保留，手动重新开启后，下次启动尊重选择。
- 设置 → 外观与动效 → UI 动效，新增“一键关闭过渡动效（流畅优先）”。
- 去掉 Dock 窗口宽度与位置过渡，取消淡入的显式 30/60 帧限制；同位置短时间重开复用背景，背景缩略图直接传递像素，避免 UI 线程重复进行 PNG 编码与解码。

## 已取消

- 移除“系统窗口美化”栏目、开关、状态和说明。
- 删除系统玻璃原生 DLL、连接程序、源代码和检测/内存测量脚本。
- 删除后台初始化与刷新加载逻辑。旧配置中的相关开关不再读取、保存或执行。
- 撤回 v0.9.24 托盘面板保持、鼠标轮询、单击延迟、双击转发和空图过滤等改动。

## 托盘入口

小球仍提供“系统托盘”入口，改为打开 Windows 原生隐藏图标区。软件图标的单击、双击和右键菜单由 Windows 与对应软件直接处理。

小球内部的复制图标网格已撤下。本版不提供嵌入在小球内部的托盘交互。Windows 原生托盘仍在系统自己的位置显示。若任务栏被手动隐藏，先恢复系统任务栏显示再打开该入口。没有隐藏图标入口时，系统托盘直接显示在任务栏。

控制中心的 Wi-Fi、蓝牙、音量、亮度、小球外观以及原生开始菜单入口保留。

## 验证

主程序已交叉编译，19 组便携回归检查通过，包含撤销功能后旧配置保留、作者素材完整性与原有功能回归。当前环境无法执行 Windows 桌面，原生托盘交互、小球连续展开与实际帧时间仍需 Windows 实机确认；这里没有实测帧率或“已稳定满帧”的结论。
